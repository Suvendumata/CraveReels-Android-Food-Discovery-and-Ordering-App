# 🍔 CraveReel – Food Discovery & Ordering App

CraveReel is an Android-based food discovery and ordering application that transforms traditional food browsing into an interactive, reel-based experience. Users can explore food reels, discover dishes, compare food items across different restaurants, view restaurant details, and add their favourite dishes to the cart.

The app also provides personalized food recommendations based on mood, cravings, budget, cuisine preferences, and available time.

## ✨ Key Features

- **Food Reels:** Explore different food items through a swipe-based, short-video-style interface.
- **Food Discovery:** Discover various dishes from multiple restaurants.
- **Food Comparison:** Compare similar food items across different restaurants based on price, ratings, cuisine, and preparation time to make better choices.
- **Restaurant Details:** View restaurant names, ratings, food prices, cuisine types, and preparation times.
- **Personalized Recommendations:** Get food suggestions based on mood, cravings, budget, cuisine, and available time.
- **Add to Cart:** Add favourite dishes to the cart.
- **Multiple Restaurants:** Explore 5 restaurants with 7 dishes each.
- **Offline Storage:** Store application data locally using Room Database.
- **User-Friendly Interface:** Simple, interactive, and modern Android UI.

## 🆚 Food Comparison Module

One of the unique features of CraveReel is its food comparison functionality.

Users can compare similar dishes available at different restaurants using:

- Food item name
- Price comparison
- Restaurant ratings
- Cuisine type
- Preparation time

This feature helps users identify the best option according to their preferences and budget.

## 📱 Application Modules

1. **Home Screen** – Displays food reels and recommended dishes.
2. **Food Discovery** – Allows users to explore available food items.
3. **Food Comparison** – Compares dishes across different restaurants.
4. **Restaurant Details** – Shows restaurant and dish information.
5. **Recommendation System** – Provides rule-based personalized food suggestions.
6. **Cart Management** – Allows users to manage selected food items.

## 🧠 Recommendation System

CraveReel uses a rule-based recommendation approach to suggest food based on:

- Mood
- Food cravings
- Budget
- Cuisine preferences
- Available preparation time

## 🚀 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/CraveReel.git
   ```

2. Open the project in Android Studio.
3. Allow Gradle to sync and download dependencies.
4. Connect an Android device or start an emulator.
5. Click **Run ▶** to launch the application.
